# Khandeshi Jodi 💍

### A Flutter-based Matrimony Application for the Khandesh Region

Khandeshi Jodi is a mobile matrimony application designed for people from the Khandesh region of Maharashtra.

The goal of the application is to provide a simple and user-friendly platform where users can create profiles and discover suitable matrimonial matches.

> 🚧 This project is currently under active development.

## 🎯 Project Goal

The application is being developed to make the matrimonial discovery process more accessible and convenient for people in the Khandesh region.

## ✨ Current Features

- 🔐 User authentication
- 📱 Profile creation
- 👤 User profile management
- 🏠 Home screen with profile discovery
- 🔎 Profile search
- 🖼️ Profile image support
- 🚪 Logout functionality

## 🚧 Currently Under Development

- Advanced profile search and filtering
- Profile details and matching flow
- Improved profile management
- Additional authentication improvements
- Notifications
- More matrimonial features

## 🛠️ Tech Stack

- **Flutter**
- **Dart**
- **Firebase Authentication**
- **Cloud Firestore**
- **Firebase Storage**
- **Provider**
- **MVVM Architecture**

## 🏗️ Architecture

The project follows a structured architecture using:

- Provider for state management
- MVVM for separation of UI and business logic
- Services layer for API, Firebase and external data handling
- Reusable Flutter widgets and common components
